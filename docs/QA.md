# GlassSlate 1.0.0 (1) — 当前验证状态

## 本轮交互修复

- 经典模式长按不再调用 iOS 26 的玻璃 contextMenu，改用系统 Popover 宿主、传统 regularMaterial 背景与经典按钮。重命名、移动到项目和删除确认都在该气泡内完成；液态玻璃模式保留原生菜单。长按后松手才呈现经典操作面板，持续按住并移动仍可交给原生拖放。
- 抽屉隐藏距离包含前缘安全区、8 pt 内缩和 48 pt 阴影余量；抽屉图层额外裁剪到视口。新增横竖屏隐藏边界和连续拖动位移的回归测试。
- 移除横屏左侧没有操作的装饰胶片图标，保留历史、设置、锁定及新建场记板工具。
- 新建项目和重命名的取消/保存使用相同的可伸展标签布局与最小高度，视觉表面等宽等高，随所选模式使用相同形状。保存中两者均禁用，避免保存尚未结束便退出编辑。
- 自定义按钮在视觉缩放之后设置稳定的完整矩形命中区域，覆盖文字/图标周围的填充区域；装饰背景不参与命中。移除抽屉的手动 Equatable 缓存，显式传入呈现状态，保证设置/新建项目按钮状态更新。
- 关闭抽屉只采用从屏幕右边缘向左滑的 UIScreenEdgePanGestureRecognizer；从左边缘向右滑展开。移除普通窗口拖动与遮罩拖动关闭。卡片内的半滑、松手、再次滑动都不满足屏幕边缘起点条件。
- 历史标题使用稳定的原生 Text，不再在显示后测量宽度并改写换行。列表水平内容边距固定，避免随抽屉移入屏幕改变。
- 跟随系统/浅色/深色三项恢复此前的圆角矩形选择样式，独立于通用胶囊按钮。
- 经典模式改为哑光表面；不再为每张滚动卡片叠加实时模糊，不再对整组文字/控件绘制阴影。阴影只绘制在背景形状上；音量控件图片按样式和主题缓存。
- 设置页原生工具栏完成按钮移除额外 glass button style，只使用系统工具栏的默认玻璃背景。
- 锁屏与展开灵动岛按钮共用 44×44 的固定圆形图标布局，保留拍板无障碍名称，不显示可能被压缩的中文按钮文字。
- 删除/撤销胶囊保留五秒。截止时间固定，新的删除重新计时，撤销取消旧提示；超时整块缩小/淡出。视图重建不会把已过期提示重新延长五秒。

## 保留的功能

- 项目文件夹：新建、持久化展开/收起、拖放归类、移动回未归类；原生上下文菜单提供不依赖拖拽的移动入口。
- 历史重命名：单独保存显示名称，不改拍板时的 8 个字段。删除/撤销保留名称与项目归属。
- 长按操作：液态玻璃模式使用 UIContextMenu 对应的 SwiftUI contextMenu 与原生确认子菜单；经典模式使用传统毛玻璃操作气泡。重命名使用原生 Popover，并强制 iPhone 的紧凑尺寸采用气泡呈现。
- 原生删除：List.swipeActions；局部左滑显露系统实心红色按钮，完整左滑直接删除，不依赖自绘拖拽按钮。
- 抽屉：保留 List 和原生菜单宿主，使用屏幕边缘专用手势和单一位移动画；不使用普通窗口拖动识别器关闭。弹出层不参与导航手势。
- 连续拍板：移除动画等待与固定音频调度等待；每次点击同步预留本条 Take，后台串行提交完整快照与下一条草稿。4 个预加载音频播放器支持前一声尚未结束时继续点击；最旧声音可被新声音替代，历史不会因此漏记。
- 玻璃形状：图标按钮 44×44 纯圆，文字操作为胶囊；经典模式保留 16 pt 按钮圆角。抽屉外圆角 38 = 控件半径 22 + 边距 16，删除/撤销状态条统一为 44 pt 高胶囊。
- 设置标题：玻璃模式使用原生 NavigationStack 的大标题与滚动边缘效果；经典模式保留独立标题。
- 经典模式：自绘哑光 51×31 开关，使用 MPVolumeView 的公开图片接口设置经典轨道与圆形滑块。始终显示恢复经典音效按钮。
- 实时活动：默认开启；包含锁屏卡片与展开灵动岛中的拍板按钮、ActivityKit 生命周期、WidgetKit 扩展、后台 AudioPlaybackIntent/LiveActivityIntent、错误反馈。Intent 与前台共用主 App 进程里的仓库和音效服务，不需要 App Group 或服务器。
- 主 App 与扩展均为 1.0.0 (1)，不再随本轮修复增加构建号。

## PASS：已执行的检查

1. Xcode 26.5，generic iOS Debug、Release 构建与 iOS 测试包编译（Logs 内保存输出）。没有启动 Simulator。
2. 15 项 macOS 单元测试通过，包含一次性 50 次点击的独立 ID、Take 顺序、全部写入与重新打开；项目、折叠状态、重命名、移出文件夹、删除撤销；原有草稿与历史回归；实时活动载荷 Unicode/字节长度约束，以及拒绝从半展开删除按钮/卡片内部启动抽屉导航的边缘策略。新增抽屉在 0/47/59 pt 安全区下包含阴影的隐藏边界与交互位移检查。
3. 使用上一版双实体 Schema 生成的真实 SQLite 文件迁移至新 Schema。原草稿和历史保留，可继续保存项目和重命名，见 Migration.log。
4. 编译器提取的文案与 en/zh-Hans String Catalog 比对，无缺失；默认 WAV 与原生 .icon 资源完整。
5. 主 App/扩展 App Intents 元数据均注册 ClapSlateIntent，包含 Audio/Live Activity 系统协议；后台执行声明和不自动打开 App 的声明存在。
6. IPA 验证：Payload、arm64、版本、扩展存在、WidgetKit 扩展点、App/扩展版本一致、双语资源、音效、图标及 ZIP CRC。
7. Classic 模式共享 SwiftUI 视图已做 macOS 原生离屏版面检查，包括横屏、新建项目等宽按钮和历史操作面板。Previews 不是 iPhone 截图；音量控件使用布局代理，弹窗宿主及箭头需在 iPhone 验证。

## 系统限制

- Live Activity 不是永久后台常驻服务；系统可以隐藏、移除或结束。Apple 文档描述通常最多活跃 8 小时，锁屏上可额外保留结束状态；App 不使用静音循环或私有 API 维持驻留。
- 系统键盘无法通过公开 API 切回 iOS 18 版本。保持 Apple 原生中文/英文输入法、系统键盘与系统外观；未冒充已恢复旧键盘。
- 原生菜单、Popover、文件选择器和系统设置由当前 iOS 绘制，不以私有方式强制换代。
- 用户自行签名 IPA 时，必须同时签名主 App 和 PlugIns/GlassSlateLiveActivity.appex，并保持有效的父子 Bundle ID。移除扩展会失去实时活动。

参考：[交互式 Widgets/Live Activities](https://developer.apple.com/documentation/widgetkit/adding-interactivity-to-widgets-and-live-activities)、[ActivityKit 生命周期](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities)、[键盘外观公开接口](https://developer.apple.com/documentation/uikit/uikeyboardappearance)。
