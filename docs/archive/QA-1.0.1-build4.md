# GlassSlate 1.0.1 (4) — 实现与验证记录

## Build 4 锁屏实时活动玻璃接入

- 锁屏内容增加 regular 原生 glassEffect 请求，并用 activityBackgroundTint(.clear) 移除默认不透明黑／白宿主底板。只有锁屏内容应用这一修饰，灵动岛仍由系统管理黑色背景。
- 使用随锁屏外观变化的 60% 黑／白保护衬底。增强对比度时为 85%；降低透明度或降低亮度（例如常亮显示）时采用实色。普通标签使用更清晰的主色层次，保持圆形拍板按钮和原 App Intent。
- 这些修改是公开 API 的材质请求，不代表已验证系统音乐卡片同款效果。WidgetKit／ActivityKit 的宿主最终决定合成，不能把编译通过当作折射和壁纸模糊已生效。若宿主忽略 glassEffect，保护衬底仅提供半透明与文字对比，不应称作已验证的 Liquid Glass。
- 没有系统音乐播放器样式模板可直接用于 ActivityConfiguration；没有使用私有 API、音乐播放伪装或静音循环。
- Build 4 重新执行 Release 构建、资源审计和 IPA 校验。28 项核心测试和 iOS 测试包编译保留 Build 2 基线，不为本轮外观变更重复运行。需要签名后的正常亮屏锁屏、不同壁纸、辅助功能、常亮显示及按钮行为测试。
- Build 3 的主 App 玻璃修正和全部数据／音频逻辑保持不变。

参考：[ActivityKit 自定义视图与默认背景](https://developer.apple.com/documentation/activitykit/creating-custom-views-for-live-activities)、[activityBackgroundTint](https://developer.apple.com/documentation/swiftui/view/activitybackgroundtint(_:))、[Live Activities HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities)。

## Build 3 玻璃透明度修正

- 根据 Build 2 的实际设备截图，撤回用于通用表面的 clear 材质，改回 regular 原生 Liquid Glass。它对底下的文字和拍板斜纹进行更强的扩散，避免历史卡片与主场记板叠字。
- 玻璃表面使用 10% 的系统表面色衬底；增强对比度为 24%，降低透明度仍采用实色。文字和图标不降低透明度，也不在内容上追加透明滤镜。
- 玻璃模式展开抽屉时，后方遮罩从 24% 调到 32%，减少主界面高对比内容的干扰。经典模式继续使用 24% 遮罩，保留原有样式。
- 版本为 1.0.1 (3)，本轮只调整玻璃样式、抽屉背景遮罩和版本／文档。Build 2 的交互、数据、Siri 音频恢复和 iPad 布局保留。
- Build 3 重新执行 Xcode Release 构建、编译器文案／资源审计及 IPA 检查。下方 28 项核心测试、iOS 测试包编译和离屏布局／动画记录来自 Build 2，未因这次外观修正重复执行。Build 3 的 iOS 27 原生玻璃效果待签名后真机复测。

## 1.0.1 保留的实现

- 项目标题支持原生长按菜单与左滑实心删除按钮。非空项目可以删除文件夹并保留记录，或连同内部记录删除；空项目只有一个删除选项。项目删除始终确认，单条记录继续支持全滑直接删除。
- 两种项目删除都使用一次 SwiftData 保存，并在错误时回滚。五秒内可以撤销；保留记录的撤销不会覆盖随后移动到其他项目的归属，也不会复活随后单独删除的记录。单条记录撤销遇到已删除项目时回到未归类，载入旧数据时修复失效归属。
- 两种外观的历史卡片统一使用原生 contextMenu。移除经典模式的自定义长按／拖动组合和 ClassicHistoryPopover。经典界面保留哑光样式，长按菜单采用当前系统原生玻璃外观。
- 抽屉使用限定物理窗口两侧 20 pt 起点的 UIPanGestureRecognizer，方向依据位移判定，无固定最低速度要求。以当前窗口尺寸计算起点，旋转时取消未完成拖动；弹窗期间暂停导航手势。卡片内部起始的滑动不能导航抽屉。
- 拍板臂由独立 keyframeAnimator 驱动：35 ms 闭合、20 ms 接触、85 ms 回弹，每次按钮触发可以重启动画。后台写入不控制拍板臂帧进度，也不阻止下一次拍板。
- 字段保存只合并本次编辑的字段，防止覆盖编辑期间实时活动已推进的 Take。历史按项目一次分组，减少重复过滤。
- Siri／电话中断结束后重新准备音频播放器，下次拍板按需激活会话。播放器失效时重建一次并重试，不循环重试或自动重放被中断的音效。处理媒体服务丢失／重启，忽略自身音频类别设置产生的路由通知，避免刚开始的拍板声被停止。正常播放继续使用四个预加载播放器。
- 实时活动拍板的保存不再被音频会话激活错误阻断；声音失败且数据保存成功时明确提示已保存。
- 自有玻璃表面统一使用 regular 原生材质与轻量系统表面衬色，文字／图标保持不透明；增强对比度增加衬色，降低透明度使用实色表面。公开 API 不提供精确透明度百分比控制，系统菜单和工具栏材质由 OS 管理。
- iPhone／iPad 通用设备族，iPad 四向旋转。iPad 窗口宽度至少 744 pt 时为 300 pt 常驻历史栏与独立场记板区域；窄窗口使用抽屉。常驻栏不显示关闭按钮、遮罩，恢复历史不收起侧栏。
- Config/Version.xcconfig 统一 App、扩展和测试目标版本，当前 1.0.1 (4)。包校验读取配置并核对 App／扩展及 iPhone／iPad 支持，无固定 1.0.0 (1) 断言。

## Build 2 PASS：保留的验证基线

1. Build 2：Xcode 26.5 通用 iOS 设备 Release 构建；Debug 的 iOS 测试包编译。测试包编译不代表已在 iOS 执行测试。
2. macOS 原生 Swift Testing：28 项测试、5 个 Suite 通过。项目删除／回滚测试分别覆盖保留和连同删除两种模式；包括磁盘重开、幂等撤销、后续移动与重命名、删除记录遇到失效项目、旧失效归属修复、字段编辑与拍板交错执行、失败拍板批次重试、五秒截止时间、慢拖方向和 iPad 布局临界值。
3. 四项音频恢复策略测试覆盖：会话中断后的下次播放激活、正常路径无需重建、失效播放器的一次重建重试、暂时激活失败恢复及持续失败的有限重试。这些是调用实际恢复策略的依赖注入测试，不是 Siri／AVAudioSession 硬件端到端测试。
4. 原有连续 50 次拍板测试继续通过，验证独立 ID、完整写入、Take 顺序与重开一致性；损坏数据不被清空的测试继续通过。
5. 131 条 en／zh-Hans 文案、默认 PCM WAV、4 层 .icon 图标资源检查通过；编译器提取键与文案目录比对无缺失。
6. 共享 SwiftUI 的原生 macOS 离屏布局检查：iPhone 横竖屏、iPad 744 pt 竖屏、深色横屏、600 pt 窄窗口及大字体环境。未见控件越界；macOS 的控件与动态字体行为并不等同于 iOS。
7. 实际 ClapperView 程序触发的离屏帧检查：触发后 45 ms 的图片显示闭合，随后重新打开；重新打开图片与初始静止图片一致。它验证共享动画实现可运动，不代替真实触摸输入测试。
8. 未签名 IPA 检查包括：ZIP CRC、Payload、arm64、App／扩展版本一致、双设备族、WidgetKit 扩展点、App Intents 元数据、图标、音效、隐私清单和双语资源。详见交付 IPA 同名 verification.json。

## 待验证：签名后真机检查

- Build 4 优先确认：关闭再开启实时活动，正常亮屏锁屏下观察壁纸是否透过、材质是否雾化与折射，并检查亮／暗壁纸、降低透明度和常亮显示。系统音乐卡片同款视觉尚未验证。

- 本轮未进行设备安装测试，没有执行模拟器启动、App 安装或运行指令，也没有下载额外运行时。编译、策略测试和 macOS 预览不作为 iOS 27／iPadOS 真机通过的依据。
- 优先复测 Siri：先拍板正常播放 → 调出 Siri 并完成问答 → 回到 App 连续拍板；检查第一声、后续声音、动画和记录均正常。再检查电话打断、锁屏返回、蓝牙／有线输出切换。
- 轻点拍板、长按松开、快速连续点击；每次有效触发独立记条，动画不会只在长按后出现。
- 两种外观下的历史长按、重命名、项目菜单、移动、拖放；两种项目删除、取消和五秒撤销。删除后立即改动归属，再撤销项目，确认新归属保留。
- 两个横屏方向和竖屏下边缘快滑／慢拖、拖动取消、旋转后再次拖动。特别检查半滑删除后松开再继续滑动不会收起页面。
- iPad 宽／窄窗口转换、旋转和分屏；历史栏常驻时的项目、设置、恢复记录及删除入口。
- 原生玻璃实际透明度、可读性、菜单、按钮边缘命中和深浅主题；系统降低透明度、增强对比度、减少动态效果及 iOS 大字体。
- 锁屏与灵动岛端到端拍板、实际声音输出、App／扩展签名和系统实时活动管理。

## 兼容与构建

- 最低系统仍为 iOS／iPadOS 26.0，经典模式不代表 iOS 18 系统兼容。保持 Bundle ID 与三种 SwiftData 实体，未清空或更换既有存储路径。
- iPad 使用当前安装的 iOS SDK，无需额外 iPad 开发包或模拟器下载。
- 主 App 和 PlugIns/GlassSlateLiveActivity.appex 都需由用户签名，保留扩展。当前交付为未签名 Release IPA。
- 每次交付新的测试 IPA 时递增构建号，失败重编可以沿用候选号。历史 1.0.0 (1) 产物不被覆盖。
